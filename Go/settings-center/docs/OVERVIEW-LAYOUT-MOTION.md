# 概览排版与动效 · 2026-11-15

## 排版参考线

大卡片不复用小卡片的固定坐标。`overview_layout.go` 提供统一参考线与文字样式。

- 内边距：24 DIP；标题行顶边：20 DIP；正文区顶边：64 DIP；底边：卡片高度减 24 DIP。
- 左侧视觉区：最多 224 DIP；正文与视觉区间隔：32 DIP。音乐、专注、待办和通知共享正文左线。
- 基础节奏：8 DIP；标题与说明间距 8–12 DIP；文字组之间 24–32 DIP。
- 空状态的说明和操作一起居中，操作不再单独钉在卡片底端。
- 待办行高 72 DIP，行间隔 8 DIP；通知行距 88 DIP，正文最多两行。

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 卡片标题 | 16 / 24 | 600 |
| 主要标题 | 24 / 32 | 600 |
| 正文 | 16 / 24 | 400 |
| 说明、时间 | 13 / 20 | 400 |
| 大数字 | 60 / 72 | 500 |

字体继续使用内嵌 HarmonyOS Sans / HarmonyOS Sans SC；时间和数字开启 `tnum`。短标题单行省略，歌词和通知正文限制行数，不与底部操作重叠。紧凑卡片继续保留独立布局。

## 动效来源及映射

来源：[用户指定的 LottieFiles motion-design skill](../../motion-design-skill/SKILL.md)。使用其中的 Premium 人格、方向性缓动、按压反馈、位置与层次组合、可打断规则。实现采用现有 MyGo 原生动画系统。

| 场景 | 实际实现 |
| --- | --- |
| 按压 / 释放 | 120ms 缩至 0.97，220ms 回到原尺寸 |
| 分段选项卡 | 同一个底板沿 X 轴移动，220ms 临界阻尼弹簧 |
| 开关 | 220ms 拇指平移，绘制动画不反复重建页面 |
| 页面 / 双概览切换 | 420ms，12 DIP 入场、0.995 缩放与透明度组合 |
| 左侧毛玻璃导航 | 320ms、24 DIP 平移；文字保持深色，不加透明度组 |
| 搜索与调色板 | 320ms、8 DIP 平移和 0.985 缩放，保留原来的小卡片布局 |
| 连续滚动 | 可反向接管的弹簧、卡壳压缩、内容淡出与边缘渐隐；不叠加额外页面入场 |

主层是卡片或面板，次层是控件和内容反馈，环境层是现有材质及边缘渐隐。空闲时不增加循环动效。开屏保持用户指定的 3.5.1 时序。

减少动态效果时取消位移与缩放，保留必要状态反馈。Windows 的“动画效果”关闭也会影响正常运行；诊断预览使用连续几何驱动检查实际变化帧，不修改系统设置。

## 验证边界

软件截图用于核对参考线与文字，原生 D3D 预览用于交互和绘制耗时。GPU 未变化的空循环不能算成有效帧，uncapped 绘制耗时也不能证明显示器达到 120Hz。
