# 点屿原创光场与玻璃短音 · 5.2 Optical

12 款内置音效全部由 `tools/generate_sounds.py` 基于**物理模态合成（硼硅玻璃、切工水晶、温润磨砂、液态水滴、木质共振）**、光学微失谐双声部颤光与微型空间早期反射原创生成，使用 G 大调（含 Maj7 / Maj9 扩展音）的统一音高体系。没有采样、裁剪或复制任何第三方录音。

技术指标严格保持兼容：44.1 kHz、单声道、16-bit PCM WAV，160–400 ms，峰值精确控制在 −13 dBFS；每个文件均从零幅度平滑淡入，并以平滑余弦曲线归零结束，零爆音，并按用户独立音量动态缩放。

柔点（磨砂轻触）、澄光（切工折射）、轻铃（硼硅风铃）、相遇（晶格磁吸）、气泡（液态水滴）、花开（极光绽放）、涟漪（静水光波）、微风（柔光气声）、木语（木质叩击）、上扬（折光轻跃）、落点（阻尼收束）、和鸣（水晶 Maj9 和弦）。

推荐：通知「柔点」、待办和计时「轻铃」、设备「相遇」。升级或重置内置音色时保留原音量、开关及自定义 WAV 路径；试听单个内置音色不会改变当前选择。
