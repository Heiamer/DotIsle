# 3.2.1 主题与动效修订

本次以用户提供的 3.2.0 Nothing 图标源码为基础。默认主题的配色、布局、图标及窗口行为保持原样；新增背景功能默认关闭。

## Nothing 对照

参考：https://github.com/dominikmartn/nothing-design-skill/tree/main/nothing-design

| 原问题 | 本次处理 |
| --- | --- |
| 主题选择像播放进度条 | 五个可点击选项块，选中块可拖动，支持键盘及重启记忆 |
| 图标大量点阵、品牌红点只是装饰 | 改为 1.5 px 单线图标，移除品牌红点 |
| 卡片 28 px 大圆角 | Nothing 卡片 12 px、选项 8 px，平面分隔 |
| 浅色背景偏深 | 按规范使用 #F5F5F5、白色卡片；深色使用 OLED 黑 |
| 字体未按角色统一 | 随包 Space Grotesk、Space Mono、Doto；居中与左对齐计时数字采用同一字体规则 |
| 歌词大字挤压译文 | 歌词正文缩小并分离正文、译文、下一行的垂直空间 |
| 数值滑块底轨与填充同色 | 新主题采用可分辨的底轨和填充；默认主题维持原样 |
| 空待办的图标与底座同色 | Nothing 移除实心底座，云瓷改用反色图标 |
| M3 弹性形变混入 Nothing | Nothing 控件使用静态形态与短颜色过渡 |

用户明确要求的图片背景和灵动岛瞬时高斯模糊属于设计规范的定向例外：背景是用户主动启用；动效只柔化过渡内容，不改变 Nothing 控制中心的稳定材质。

## 新主题

- 云瓷：暖灰、瓷白、亮蓝、圆润卡片与白色滑钮，参考用户仪表盘截图。
- 终端 TTY：等宽字符控件、方正边框、色块唱片和离散进度，保留可点击操作。
- 像素 Pixel：中英文字体采用 Fusion Pixel 12px，方块图标、卡带精灵、阶梯边框与 16 位机配色，支持明暗模式。
- 五套主题分别保存本地图片背景、透明度、明暗、磨砂度和适应方式；旧三套/四套背景配置迁移后保留。

## 展开与收起

复用现有可中断弹簧及自定义曲线。仅内容层应用真正的 GPU Gaussian，峰值 1.35 dp，轮廓不模糊。展开和收起使用同一个形态进度推导模糊，反向时不跳变。端点及减少动态效果时不启用滤镜。

本机生产渲染的合成音乐场景共 123 帧（展开、收起、反向），绘制完成 P95 约 4.24 ms，包含 GPU 等待、不包含系统调度，不能代替所有硬件上的实际帧率。

## 网易云验证边界

已修复通道轮询延迟及旧请求投递前的代次检查，优先系统媒体和已有本机 CDP 通道。当前客户端实测首次连接约 198 ms，10 次真实进度确认约 186–198 ms，快速连续请求确认最终目标，注意力请求记录为 0，测试后恢复原播放状态和位置。

当前客户端没有暴露可用的系统媒体暂停会话，暂停态未通过验收；不宣称所有客户端版本、最小化及托盘组合的闪窗问题均已解决。
