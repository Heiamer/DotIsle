# 点屿插件 API v1 · RC1

「插件 → 内置插件」中的久坐提醒和喝水提醒由点屿在本机调度，不使用下文的开放插件 API。两者默认关闭，须分别输入并保存 1–1440 分钟后启用。久坐提醒估算连续用机时间，锁屏或离席约 5 分钟后重新计时，不检测实际坐姿；喝水提醒累计活跃用机时间，离席时暂停。系统休眠不计时，暂停通知或手动隐藏灵动岛时不补发。重启保留设置，并开始新的计时周期。

插件以积木清单和实时 JSON 数据组成。同一插件可以同时上灵动岛、概览卡片、桌面组件，不需要重编译点屿，也不用编写 DLL。RC1 开放的是数据驱动插件；Python、Node、Go、Rust 等程序均可作为独立数据生产者。点屿不会自动运行插件文件夹内的代码。

## 两分钟运行示例

1. 将 `examples/plugins/hello` 复制到自己的固定目录。
2. 控制中心 → 插件 → 添加本地插件，选择包含 `manifest.json` 的目录。
3. 灵动岛会出现该插件活动；通过横向切换活动选择它，悬停展开。经典和 Mini 共用展开内容。
4. 在插件页点击“添加到概览”或“添加到桌面”。概览卡可照常长按排序和拖角缩放；滚动视图及信息组件的自定义目录也包含插件。
5. 在示例目录执行 `python producer.py`。示例计数与进度每秒变化；关闭生产者会停留在最后的数据。
6. 修改清单或数据后，约一秒自动刷新。停用与移除不会删除用户插件目录；移除后已有卡片显示不可用，重新安装相同 ID 可恢复。

安装信息保存在用户数据目录的 `plugins.json`，由点屿主进程写入。插件文件夹保持在用户选择的原位置，移动后需要移除再添加。

## 清单

```json
{
  "apiVersion": 1,
  "id": "example.hello",
  "name": "我的第一块积木",
  "version": "1.0.0",
  "description": "同一份数据，三种展示位置。",
  "views": {
    "island": [
      {"kind": "metric", "bind": "counter", "label": "已运行秒数"},
      {"kind": "progress", "bind": "progress", "label": "本轮进度"}
    ],
    "overview": [
      {"kind": "text", "text": "你好，点屿"},
      {"kind": "metric", "bind": "counter", "label": "已运行秒数"}
    ],
    "desktop": [
      {"kind": "metric", "bind": "counter", "label": "已运行秒数"}
    ]
  }
}
```

`id` 只允许小写 ASCII 字母、数字、`.`、`-`，1–64 字节，不能以点开头或结尾，也不能含 `..`。相同 ID 不允许重复安装。名称最多 40 字符，版本最多 32 字节，说明最多 180 字符。至少定义一个展示位置；不声明的位置不会出现对应添加按钮。

## 积木

积木按数组顺序纵向排列，使用宿主字体、材质、配色和连续曲线卡片。内容不包含 HTML、CSS、脚本或任意绘制指令。

| kind | 用途 | 字段 | 标准高度 |
| --- | --- | --- | --- |
| `text` | 一行说明 | `text` 或 `bind` | 28 DIP |
| `metric` | 主数字与下方说明 | `text` 或 `bind`，`label` | 56 DIP |
| `progress` | 说明及进度条 | `value` 或 `bind`，`label` | 40 DIP |
| `divider` | 分隔线 | 无 | 12 DIP |

每个展示位置最多 8 块，总高度不超过 260 DIP。桌面默认添加大尺寸；改成较小尺寸时按可用高度缩放内容。建议小组件正文总高度保持在 100 DIP 内。文字为单行裁切，最多 160 字符；label 最多 40 字符。

`bind` 是插件自己的 `state.json` 中的字段路径，例如 `weather.temperature`；路径只允许字母、数字、下划线和分隔点，不支持数组、表达式或调用。绑定值可为字符串、数字或布尔值。字段缺失显示 `—`。进度限制在 0–1；无有效数字时使用清单的 `value`（缺省为 0）。控制字符会移除。

## 实时数据

`state.json` 可选，初始缺省为 `{}`。它必须是 JSON 对象，最多 128 KiB。清单最多 64 KiB。请用临时文件加原子替换写入，避免读到半份 JSON。示例生产者已演示这种写法。

刷新频率最高每秒一次。插件停止更新时保留最后的文件值，宿主不会编造数据或将静态值宣称为实时读数。需要时效提示时，可以自行提供 `updatedAt`、`status` 等字段并绑定成 text。

插件不获得点屿通知、音乐、账号或文件的隐式访问权限。生产者获取自己所需的数据并写入 state。RC1 不提供宿主命令执行、自动启动生产者、网络下载插件、通知推送动作或 DLL 扩展权限。

## 安装与故障处理

最多安装 32 个插件，桌面组件仍遵守最多 16 个实例的限制。无效 API 版本、未知积木、过大文件和无效内容会拒绝安装。运行中清单或 state 损坏会显示插件错误，并暂停该插件的活动与渲染，不影响其他插件；修复文件后自动恢复。插件页可独立启停和移除。

内部管道协议版本仍为 1：`pluginInstall` 的 value 为 `{ "path": "绝对目录" }`，`pluginEnable` 为 `{ "id": "插件ID", "enabled": true }`，`pluginRemove` 为 `{ "id": "插件ID" }`。返回 `success` 和 `message`；成功返回最新 `plugins`。`state.plugins` 包含 id/name/version/description/enabled/error，以及各展示位置已解析的 blocks。生产者通常无需调用管道。

这些开放插件与 `docs/CORE-MODULES.md` 中用于点屿自身升级的内部业务 DLL 是两种契约，请勿将 DLL 当成插件目录安装。
