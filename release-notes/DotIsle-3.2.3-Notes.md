# 点屿 DotIsle 3.2.3

- 专辑封面直接使用播放器提供的原图：移除终端 ASCII / 半块字符转换、RGB565、像素化和调色板滤镜；保留终端和像素主题的控件、字体及进度风格。
- 「云瓷」由 MIUIX 风格替换，参照 compose-miuix-ui/miuix 的分组、蓝色配色、16 dp 连续圆角、49×28 dp 开关及轻量交互。旧云瓷主题和图片背景自动迁移到 MIUIX。
- 新增第六套「Swiss · 瑞士国际风格」：左对齐无衬线排版、编号与网格、不对称音乐版式、黑白纸色及少量红色强调；包含重新绘制的几何图标，支持明暗。
- 六套主题支持选项块点击、拖动、方向键切换和重启记忆；每套主题独立保存图片背景、透明度、明暗与磨砂参数。
- 默认主题保留原有外观与窗口行为。网易云版本白名单移除及已验证的进度控制继续保留。

## 构建与验收

GitHub Actions 构建安装包、便携包及源码，发布前要求控制中心、六主题/背景和原图/进度的四份报告全部通过。
网易云 3.1.43.205627 的连接、连续跳转、暂停后跳转及原状态恢复由 3.2.2 实机验证，本版未改动其控制实现；其他版本和窗口状态仍按实际能力检测。
