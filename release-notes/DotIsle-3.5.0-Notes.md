# 点屿 3.5.0 · 第一版开发预览

这是半代升级的第一版，后续仍会继续加入功能。本包供本地体验和验证。

- 一体式胶囊底栏；概览采用双向无限循环的叠放卡片，直接操作播放、进度、歌词同步、专注、待办、通知与桌面组件。
- 原生灵动岛布局编辑器：拖动封面、文字、播放按钮与进度条，支持吸附、宽度调整、方向键微调和撤销重做。
- 整合 10 套播放按钮主题、8 种进度条、16 种滑块，并使用真实组件预览。
- 新版「留白」画廊主题替代 Swiss；新增海军蓝与蓝紫强调的「夜航」主题。旧 Swiss 的主题背景会自动保留。
- 采用所选的纤细倾斜 Dotisle 手写字标；关于页和打开设置时的书写动画共用同一份矢量图。支持跳过与减少动态效果。
- 六类桌面组件：时钟、日历、待办、专注计时、音乐、系统状态，支持三种尺寸与位置记忆。
- 灵动岛与通用设置按用途合并分级，新增通知中心。
- 灵动岛开机问候；空闲通知退出后直接隐藏，播放中的通知则恢复音乐胶囊。
- 更新接管弹窗统一材质与连续曲率，移除白色描边。
- 保留 3.2.7 的番茄钟阶段结算与流程操作版本校验。

本次为本地开发预览，未提交、推送或发布正式版本。
