# 点屿 DotIsle 3.5.0

3.5.0 是一次半代升级：新的控制中心、可以直接操作的概览卡片，以及可自由组合的灵动岛布局。

## 控制中心与概览

- 一体式胶囊底栏统一概览、组件、计时、待办、通知与设置入口。
- 概览使用双向无限循环卡片，支持滚轮、拖动与方向键跨圈切换；播放、进度、专注计时、待办与通知可在卡片内完成常用操作。
- 移除音乐卡片右上角多余的布局入口，卡片只保留音乐内容与播放操作。
- 音乐卡片按两列参考线重排，歌词统一移到进度条上方，采用 AMLL 式连续滚动、前后行淡化模糊和真实逐字进度。
- 音乐卡片以专辑封面铺底，配合真实背景模糊、文字遮罩和亚克力材质；无封面时自动回退。
- 卡片上下使用渐变透明磨砂，柔化滚动边缘并消除底栏附近的缝隙。

## 自定义布局与桌面组件

- 灵动岛布局编辑器整合封面、歌曲信息、歌词、播放按钮与进度条，可拖动、排列、吸附、调宽及方向键微调，并支持撤销、重做和原子应用。
- 提供 10 套播放按钮主题、8 种进度条与 16 种滑块，使用真实预览。
- 时钟、日历、待办、专注计时、音乐、系统状态六类桌面组件，支持三种尺寸和位置记忆。
- 每个组件独立保存风格，六套风格完整列出，不随控制中心主题变化。

## 设置与外观

- 全页面统一外边距、卡片内边距、分组节奏及控件基线，按双尺寸检查各主题与展开状态。
- 设置数值滑杆统一为 MIUIX 套件式圆润轨道和白色滑块，覆盖尺寸、透明度、音量、动效及背景参数；音乐卡片的播放进度样式独立保留。

- 灵动岛设置与通用设置按用途分级；关于、通用与计时偏好直接进入内容。
- 移除设置首页重复开关，右上角明确为显示／隐藏灵动岛，状态与空闲自动退场分离。
- 去掉设置子项切换时的整页上移与淡入，并清理旧页面滚动惯性。
- 六套主题：默认、Nothing、MIUIX、终端、像素与留白；删除夜航，旧配置回退默认。
- 控制中心保留连续曲线，原生灵动岛恢复普通圆角胶囊。
- 设置开场、关于页及 README 共用单色 Dotisle 手写字标。

## 动效与资源

- 修复空白歌词、展开内容交叉淡化空档，以及通知和托盘双击展开后收回时残留空黑块的问题。
- 灵动岛启动时显示简短时段问候；空闲通知整体退场，播放中恢复音乐胶囊。
- 更新弹窗统一材质并移除白边。
- 主题字体按需加载，清空绘图场景时避免复制整帧；原生状态同步有界排队并跳过重复快照。
- 关闭设置后，无桌面组件时约 10 秒释放设置进程；有桌面组件时继续运行。
- 拆分原生状态同步模块，整理窗口事件、文字渲染与场景代码，改善后续维护。
- 保留番茄钟阶段结算、过期流程操作拒绝及播放器进度修复。

## 验证与下载

本地完整工作区 471 项 Rust 测试通过，六主题、深浅色及双尺寸共 3288 个页面状态未发现控件交叠，并通过原生 GPU 截图、六主题、设置切换、布局保存、组件持久化、通知退出和真实托盘回调验证。正式包由 GitHub Actions 从 main 主线构建并验收。

- `DotIsle-3.5.0-Setup.exe`：安装版。
- `DotIsle-3.5.0-Portable.zip`：完整解压后运行 `LyricIsland.exe`。
- `DotIsle-3.5.0-SHA256.txt`：下载文件校验值。
- `DotIsle-3.5.0-Validation.zip`：构建与界面验收记录。

本次为正式版本；3.5.0-rc1 用户可升级到 3.5.0。
