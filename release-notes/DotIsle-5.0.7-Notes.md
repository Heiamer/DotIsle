# 点屿 DotIsle 5.0.7

- 灵动岛常驻默认关闭。开启后可选轮播本地时间、CPU 与内存占用和已连接设备电量。没有连接设备会跳过电量项，电量不可读取时显示未知。点击胶囊可查看系统概况、已连接设备和快捷操作。
- 降低灵动岛与控制中心的资源占用。主岛与底部提示共享封面像素，滤镜按需加载。关闭控制中心后回收窗口资源，并按桌面组件状态退出闲置进程。
- 插件加入喝水和久坐提醒，用户可分别设定间隔并启用。
- 增加版本更新说明。控制中心更新前先展示变更内容，经确认再下载。更新按新包提供的清单校验文件，支持新版移除组件。
- 音乐进度条默认采用标准样式。布局编辑器接入灵动岛原生预览。微信、QQ 通知包含可读取的本地联系人头像时优先显示头像。
