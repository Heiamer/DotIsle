# 点屿 DotIsle 3.2.5

- 网易云正常启动就能自动接入进度，无需脚本、特殊参数或重启。
- 保持后台、最小化和隐藏托盘时拖动进度的体验，不唤起播放器窗口。
- 独立重写只读播放状态连接，保留真实回读、快速拖动合并和切歌保护。
- 修复网易云播放/暂停已生效却被系统媒体回报延迟误判失败的问题。
- 修复进度条圆角两端无法开始拖动，以及末尾像素取整导致真实跳转被误判失败的问题。
- 更新设置页与连接状态说明。

本次原生进度适配并实测网易云 Windows x64 3.1.43.205627；其他客户端版本使用系统媒体会话，后续可增加独立适配。
