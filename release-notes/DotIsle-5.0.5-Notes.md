# 点屿 DotIsle 5.0.5

天气扩展为七个服务适配器，新增未配置城市引导与更新成功后自动清理。

- 天气池：QQ 天气、今日头条、Open-Meteo、MET Norway、DWD / Bright Sky、wttr.in、7Timer。某源超时、数据缺失或过期时继续尝试；获得完整预报即返回。小时预报优先于三小时预报，同档参考实际响应时间；不宣称已获得实地准确率排名。
- 国内零配置：不要求注册或填写密钥。部分公开网页接口可能变化，失败时自动降级。关闭代理后逐源测试中国城市，实测结果随验证记录提供。
- 降水提醒：展示预计时段和来源时间粒度，缺少概率不补数；中国地区小时插值与三小时模型不标为分钟级临近预报。
- 城市引导：打开控制中心且没有城市时弹窗填写，已有概览或桌面天气组件城市会沿用；稍后填写只在下次打开时再提醒，保存失败保留输入。
- 更新清理：使用本版更新器完成升级并确认新版启动后，清理本次临时包、备份及未修改的旧分发文件。失败回滚保留备份；用户数据、新增文件和修改过的文件保留，不扫描其他旧版文件夹。

安装包、便携版和源码见 Assets。
