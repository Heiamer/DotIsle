# 点屿 DotIsle V5.0RC1

这是 5.0 的第一个 Release Candidate，供测试通道使用。默认正式版通道继续使用 3.5.3。

## 控制中心

- 全新 Go / Direct3D 原生控制中心，固定窗口、HarmonyOS Sans、连续曲线卡片与分层阴影。
- 左侧白色毛玻璃导航、紧凑搜索与调色板；概览支持卡片与滚动两种视图，自定义组件、排列、尺寸和滚动页。
- 音乐卡片恢复磨砂专辑封面背景；日历、用机时长、日程倒计时和无线设备电量可选。
- 动态取色 Beta 默认关闭，启用后使用低饱和浅彩色；开关和文字按统一参考线排版。
- 保留 3.5.1 开屏节奏，加入页面、按压、开关、导航与弹层动效，支持减少动态效果。

## 灵动岛和更新

- 设备连接与低电量、验证码、天气降水时段和开机问候加入胶囊活动；Mini 可展开并回到原尺寸。
- 微信、飞书、钉钉和企业微信只显示应用图标与“有新消息”，不读取这些应用的通知正文。基于任务栏闪烁及系统通知元数据，带独立开关和去重。
- 更新器提供正式版和测试版通道，默认正式版；模块升级支持校验、替换和失败回滚。

## 插件积木

- 侧边栏新增插件管理，支持添加本地插件、启停和移除。
- 同一插件的文字、数字、进度与分隔积木可接入灵动岛、概览和桌面，通过自己的 JSON 数据实时更新。
- 附开发文档 `docs/PLUGIN-DEVELOPMENT.md` 与 `examples/plugins/hello` 可运行示例。数据生产者独立运行，点屿不自动执行第三方代码。
- 音乐灵动岛新增滚轮音量按钮与当前百分比提示。

## 测试说明

- 部分客户端只改变托盘红点而不发送任务栏或系统通知时，消息提示可能无法触发；四个真实客户端组合仍需兼容性反馈。
- 滚动性能随显卡、DPI 和系统合成而变，本版本不承诺所有设备稳定 120Hz。
- 天气需填写城市并联网；用机时长只记录点屿运行期间的活跃使用。

建议保留现有配置备份后体验预发行版。
