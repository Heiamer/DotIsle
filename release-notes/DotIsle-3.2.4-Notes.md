# 点屿 DotIsle 3.2.4

- 更新歌词核心、匹配、时间轴、缓存、本地检索和六个在线歌词适配器；首次播放会重新获取歌词，原设置继续保留。
- 网易云进度采用本机页面通道，移除进程内存扫描。系统媒体会话仍可独立提供信息；启用页面通道需先完全退出网易云，再通过随包 Start-NetEase-SilentControl.cmd 启动。
- 修复网易云播放与暂停识别相反、恢复暂停歌曲时缺少进度，以及页面采样短暂中断时进度归零的问题。
- 保留同曲短暂断档的显示连续性；过期样本不用于提交或确认进度跳转。
- 更新原生抽屉弹簧及中断衔接，保留六套主题、计时、待办、通知和更新功能。
- 项目自有代码使用 MIT 许可，Copyright (c) 2026 Heiamer；随包保留当前第三方依赖和字体许可。

本机实测：网易云 3.1.43.205627，前台、最小化、隐藏托盘均通过；共 33 次连续暂停跳转、各场景 5 次快速请求，以及真实歌词、播放恢复和原生进度条操作通过。393 项 Rust 回归、9 项页面读取检查通过。其他播放器版本、视频与播客不在本次实测范围。

请先退出旧点屿，再运行新版。完整解压便携包，勿在压缩包内直接运行。手动迁移时备份原 Data，再复制到新版目录。网易云连接说明见 NETEASE-SEEKFIX.md。

发行包由 GitHub Actions 从对应提交独立构建，SHA256 清单可用于校验附件。
