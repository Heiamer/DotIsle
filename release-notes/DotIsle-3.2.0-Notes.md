# 点屿 3.2.0 · 播放主题、进度条与字体

- 新增 10 套播放器主题：礁石、涟漪、细砂、晨雾、琉璃、墨屿、双潮、留白、光环、叠影。礁石沿用现有图标，其余九套分别使用 Tabler、Material Symbols 描边、Phosphor（Fill/Bold）、Lucide、Bootstrap Icons、Remix Icon、Feather、Heroicons 的完整图标集；按钮位置、点击区域与控制功能保持不变。
- 播放进度条新增 8 种样式（Normal、Wavy、Rounded、Thin、Thick、Gradient、Segmented、Dots），默认 Wavy。滑块改为独立开关，默认关闭；开启后可选 16 种造型，并可用「滑块缓慢旋转」让它缓慢自转（默认关闭）。样式只作用于带滑块的播放进度条，计时、更新等进度条保持原样。
- 灵动岛字体可使用本机已安装字体：搜索、单行预览、点「确认更换」后应用，可一键恢复默认。文字改为按基线绘制，修复展开后字体错位，并让不同行高、字重的第三方字体保持同一视觉位置。
- 播放器响应范围改为「所有播放器 / 指定播放器」两种模式；指定模式展开选择菜单。浏览器媒体改为独立开关，默认关闭；默认响应所有播放器。
- 更新提醒新增「不再提醒」：只跳过当前版本，发布下一个版本后会再次提醒；更新页可恢复此次更新。更新提醒展开卡片重新分配表盘、标题、两行说明和底部按钮的空间，说明不再被按钮遮挡。
- 番茄钟、正计时、流程和倒计时卡片右上角新增结束按钮，点击结束并收起当前任务。
- 更新检查仓库切换为 https://github.com/Heiamer/DotIsle；修复已是最新版本时仍显示远端旧版本号的标题。
- 玻璃材质的边缘光线折射由约 1px 增加到约 3px，并降低亮度，保持含蓄。

验证：工作区全部测试通过；设置端 `--verify` 生成本地截图与检查报告；release 构建与安装包、便携包、OTA 兼容包打包脚本通过。未向真实播放器发送控制命令。

Windows 10 / 11 x64。安装版、便携版、对应源码、验证记录及 SHA256 校验随版本提供。
