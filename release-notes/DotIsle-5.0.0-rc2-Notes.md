# 点屿 DotIsle V5.0RC2

RC2 集中修复 RC1 的控制中心、桌面组件与灵动岛交互问题。请在测试版通道获取；正式版通道保持独立。

## 控制中心与桌面组件

- 统一使用 Go 控制中心，桌面组件通过原生 C ABI 在同一进程运行，删除旧设置程序和重复入口。
- 修复桌面组件移除失效和主程序退出后残留窗口；重新启动后恢复已保存的组件与位置。
- 灵动岛布局编辑器改为双栏：左侧实时预览，右侧分组选项与位置、宽度滑块；修正点选、撤销和拖动历史问题。
- 滚动视图卡片统一大小与间距，修复音乐卡片四角露底、小尺寸专注组件遮挡及手势教程入口。

## 灵动岛与开屏

- 验证码来源、完整数字和复制操作重新排版；长来源名称省略，4／6／8 位码保持完整，复制成功与失败原位反馈。
- Mini 与经典岛展开、收起时保持内容位置和字号，补回复制图标，避免半截数字与文字重叠。
- 非音乐展开卡片增加删除按钮和悬停提示，点击直接删除相应任务或岛上卡片；待办清单和后台更新任务保留。
- 更新开屏、关于页和 README 字标，正文保持 HarmonyOS Sans；开屏支持跳过和减少动态效果。

## 更新与验证

- 升级安装清理旧设置程序，更新走完整软件包，避免仅替换部分组件造成版本混用。
- 本地构建、生产渲染截图、桌面组件持久化与进程退出、计时器、模块替换及回滚通过后，由 GitHub Actions 核验并发布相同文件。
- 发布页仅保留安装包、便携包、源码与 SHA-256 校验文件；测试报告和内部模块包不作为用户下载项展示。
