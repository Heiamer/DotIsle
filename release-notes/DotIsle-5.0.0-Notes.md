# 点屿 DotIsle 5.0.0（symphony · 开发中）

本版本代号 symphony，正在开发中。当前已完成 3.5.2 撤回问题的修复：

## 稳定性与修复

- 修复控制中心隐藏后无法再次打开、重复打开同一页面不响应的问题。
- 修复音乐卡片歌曲、歌词、进度与播放控件读取错误状态字段的问题。
- 修复模块安装等待控制中心退出超时，操作失败现在会显示原因；主程序重启后继续同步。
- 修复待办弹窗重复绘制、减少动态效果开关方向及首次偏好保存失败。
- 新包强制携带当前控制中心；安装升级时纳入控制中心的文件占用处理。

- 修复设置窗口与主程序之间的命名管道竞态（3.5.2 撤回原因）：服务端不再在每个请求后销毁并重建管道实例，客户端不会再连接到"即将关闭"的实例，杜绝保存设置时偶发的 `0x800700E9（管道的另一端上无任何进程）`。
- 设置进程首次连接失败时先确认主程序单实例互斥，命中则退避重试，不再误启动第二个主程序触发单实例弹窗。
- 管道客户端对只读请求（state）在 233 / 109 错误上短暂退避重试；变更请求保持"仅写入失败时重试、绝不重放已送达的变更"。
- 单实例弹窗的版本查询改用与环境一致的管道名（含测试管道），避免误报「版本未知」。
- 新增并发回归测试：多客户端并发 state 请求，管道断开次数必须为 0。

## 说明

- 3.5.2 已从 GitHub / Gitee 撤回；其修复内容并入本版本。
- 下载与校验文件将在本版本正式发布时提供。
