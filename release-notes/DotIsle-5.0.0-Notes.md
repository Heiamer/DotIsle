# 点屿 DotIsle V5.0

5.0 正式版把控制中心、灵动岛和桌面组件收进同一套原生实现：Go 控制中心负责界面，Rust 主程序负责音乐、计时、待办与通知，桌面组件通过 C ABI 在控制中心进程内运行。

## 控制中心与信息组件

- 概览支持卡片与滚动两种视图；卡片可调整排列、拖动边角改变大小，滚动页可增删和排序。
- 概览、滚动视图与信息组件页中的天气、存储空间、世界时钟、便签、纪念日、日程倒计时和快捷启动，添加后即可在卡片右上角直接设置，不再要求先在桌面添加同名组件。
- 卡片设置窗提供城市与磁盘快捷选项，便签使用多行编辑，快捷启动可选择本地程序或快捷方式；设置保存在本机，重启后自动恢复。
- 自动读取的日历、电量、电脑状态、用机时长、专注统计与今日概览不再显示无效的“...”入口；电脑状态在缺少容量明细时显示内存占用百分比。
- 控制中心只跟随自己数据目录的点屿实例，修复一次点击托盘“设置”弹出多个相同窗口；重复启动会唤起已有窗口。

## 灵动岛与桌面

- 音乐岛显示歌曲、封面、原文与翻译，支持播放暂停、切歌、进度与音量；验证码、设备连接、待办与计时提醒进入岛体。
- 桌面组件提供时钟、日历、待办、专注、音乐、天气、便签、纪念日、电池、存储、世界时钟、快捷启动、专注统计、无线设备电量、日程倒计时与用机时长，支持三种尺寸和完整配置。
- 插件积木 API v1 可把文字、数值和进度接到灵动岛、概览与桌面。

## 稳定性与修复

- 修复 3.5.2 撤回的设置管道竞态：只读 state 请求短暂退避重试，变更请求绝不重放；并发 state 请求回归测试通过。
- 修复控制中心隐藏后无法再次打开、重复打开同一页面不响应、待办弹窗重复绘制与减少动态效果开关方向。
- 模块安装失败会显示原因；主程序重启后继续同步。损坏的更新模块不再触发 Windows 系统错误弹窗。

## 更新与验证

- 本地完成 Go 与 Rust 测试、全页面截图、独立信息组件读数、重启持久化、残留控制中心隔离、计时器验收与打包 UI 验收后再发布。
- 天气读数需要网络；离线时会显示“天气暂不可用”，修改城市后自动重试。
- 云母、模糊与实际流畅度受 Windows 版本、显卡、DPI 与系统合成影响，5.0 不承诺所有设备稳定 120Hz。
