# 点屿 DotIsle 3.5.0-rc1

3.5.0 半代升级的首个候选版本，后续仍将继续完善和增加功能。

## 新的控制中心

- 一体式胶囊底栏，概览、组件、计时、待办、通知、设置统一入口。
- 概览采用双向无限循环叠卡，支持滚轮、拖动和方向键跨圈切换。
- 在卡片内完成播放、进度、歌词偏移、计时、待办和通知等常用操作。
- 灵动岛设置与通用设置按用途合并分级，新增通知中心。

## 自定义灵动岛与桌面组件

- 模块化布局编辑器，可直接拖动封面、文字、播放控件与进度条。
- 支持吸附、宽度调整、方向键微调、撤销和重做。
- 整合 10 套播放按钮主题、8 种进度条与 16 种滑块，提供真实组件预览。
- 六类原生桌面组件：时钟、日历、待办、专注计时、音乐、系统状态；支持三种尺寸和位置记忆。

## 外观与动画

- Swiss 重设计并更名为「留白」，保留旧主题背景；新增深蓝与蓝紫风格的「夜航」。
- 全新细笔画倾斜 Dotisle 手写字标，关于页与打开设置时的书写动画共用同一字形。
- 使用连续曲率；书写动画可跳过并支持减少动态效果。
- 灵动岛启动时显示简短问候；空闲通知结束直接退场，播放中恢复音乐胶囊。
- 更新弹窗材质统一，移除白边，修正小窗口进度与按钮间距。
- 保留 3.2.7 的番茄钟阶段结算与流程操作版本校验修复。

## 下载

- `DotIsle-3.5.0-rc1-Setup.exe`：安装版。
- `DotIsle-3.5.0-rc1-Portable.zip`：完整解压后运行 `LyricIsland.exe`。
- `DotIsle-3.5.0-rc1-SHA256.txt`：下载文件校验值。

本版本由 GitHub Actions 从 main 主线的候选版本标签构建并发布为 Pre-release。
正式版用户的自动更新通道保持不变；RC 可升级到后续的 3.5.0 正式版。
