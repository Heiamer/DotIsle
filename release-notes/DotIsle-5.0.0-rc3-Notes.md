# 点屿 DotIsle V5.0RC3

RC3 修复信息组件必须依附桌面组件、设置入口一次弹出多个相同窗口的问题。请在测试版通道获取；正式版通道保持独立。

## 信息组件

- 概览卡片、滚动视图与信息组件页中的天气、存储空间、世界时钟、便签、纪念日、日程倒计时和快捷启动，添加后即可在卡片右上角直接设置，不再要求先在桌面添加同名组件。
- 天气城市、磁盘、世界时钟城市、便签内容、纪念日日期、日程时间与快捷启动目标保存在本机，重启后自动恢复；卡片直接显示对应读数。
- 卡片设置窗提供城市与磁盘快捷选项，便签使用多行编辑，快捷启动可选择本地程序或快捷方式。
- 自动读取的日历、电量、电脑状态、用机时长、专注统计与今日概览不再显示无效的“...”入口；电脑状态在缺少容量明细时显示内存占用百分比。

## 控制中心

- 修复一次点击托盘“设置”弹出多个相同控制中心窗口：控制中心只跟随自己数据目录的点屿实例，其他残留实例连接后自动退出。
- 重复启动控制中心会唤起已有窗口，而不是静默退出。

## 验证

- 本地完成 Go 与 Rust 测试、控制中心生产截图、独立信息组件读数、重启持久化、残留实例隔离和打包 UI 验收后再发布。
- 天气读数需要网络；离线时会显示“天气暂不可用”，修改城市后自动重试。
