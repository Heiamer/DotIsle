# 点屿 DotIsle 5.1.0

- 微信消息恢复为只读取本机聊天库中的新文字消息；不再依赖 Windows 系统通知，也不再用系统通知兜底。系统通知里的微信条目只用来识别应用，不会当作聊天正文。
- 按会话状态过滤微信提醒：消息免打扰、折叠聊天、不显示该聊天的会话不再上岛。群聊按群会话本身判断，不按发消息的成员判断。
- 联系人的消息免打扰与黑名单同样不提醒。被过滤的会话会推进读取位置，解除免打扰后只提醒新消息，不补弹旧消息。
- 播放按钮主题卡片下方的主题名称改为居中显示，和卡片里的按钮预览对齐。
- 重做控制中心侧边栏：更紧凑的宽度、统一的导航项与图标、主题色玻璃背景，页面较多时可以滚动。
- 设置卡片、侧边栏和弹层应用连续圆角曲线，边缘过渡更连贯。
- 播放进度条的样式预览改由灵动岛原生渲染并回传，预览与实际播放样式一致；原生预览暂不可用时显示提示并自动重试。
- 修复控制中心更改设置后偶发的黑色提示块。提示条改用当前主题的背景色和描边，不再使用取反的深色底。
- 版本号更新为 5.1.0。

微信正文仍只在本机只读解析，不生成明文数据库、密钥文件或聊天记录副本。客户端数据结构变化时可能影响可用性。
