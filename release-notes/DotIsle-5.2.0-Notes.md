# 点屿 DotIsle 5.2.0

- 控制中心仅使用 D3D11 硬件渲染，禁止软件回退；限制旧页面纹理缓存以保留低内存占用。
- 移除「液态玻璃」和实时桌面折射；旧配置自动切到「曜光玻璃」，亚克力歌曲封面不受影响。
- 重制「曜光玻璃（Lumen Glass）」材质与原版高级氛围色场亚克力质感，开放通知/OSD 弹窗独立材质选择（默认亚克力）及灵动岛整体透明度调节。
- 重制 3 套原创桌面端音乐展开布局并新增光效动画、动态三柱声波与动态歌词引导光柱；修复「灵动岛颜色来源于专辑」取色联动。
- 彻底重构高精度歌词搜索与多平台匹配引擎（繁简折叠、feat 提取、版本噪声过滤、时长精准惩罚与双语别名匹配）。
- 极简重制灵动岛与控制中心番茄钟、支持待办滚动浏览全部任务；全新推出「任务栏歌词模式」，支持任务栏实时逐字歌词与副行译文、自由调节位置与宽度、常驻显示时间与系统状态及向上展开完整卡片，同时保持通知与系统提示照常在屏幕正上方弹出。
- 支持多显示器独立选择、修复自由悬浮直拖体验与隐藏状态通知正常弹出唤醒，并新增「隐藏后触碰屏幕边缘显示」开关。
