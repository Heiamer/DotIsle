# 点屿 3.5.3 · 更新器紧急修复

基于 3.5.1 正式版发布，保留原有功能、界面与本机数据。

- 软件更新新增「正式版 / 测试版」通道，默认正式版。
- 测试版通道可获取已发布的预览版本，也可升级到后续正式版；不会自动降级。
- 切换通道后重新检查，通道选择在重启后保留。下载、校验和安装期间锁定通道，防止更新包错配。
- 双源检查按版本选择完整更新包，继续校验 SHA256，并保留取消、安装确认和失败回滚。
- 兼容 3.5.1 的 OTA 入口，更新完成后可在「设置 → 软件更新」选择通道。

下载和安装仍由用户确认。切回正式版后，如果当前测试版高于正式版，将等待后续正式版发布，不会强制降级。
