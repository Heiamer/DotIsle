# 点屿 DotIsle 3.5.2

本次更新把主程序与控制中心拆分为可独立替换的 DLL，加入设置内的模块管理，并让更新器按内容摘要只下载变化的模块包。

## 模块化与独立更新

- 主程序与控制中心加入固定 C ABI v1 的启动边界，启动时校验每个模块的角色与版本。
- 十三个业务服务迁入独立 DLL：专注、待办、音乐、歌词、通知、历史、自动化、设备、OSD、音效、组件、主题与光效。
- 音效与播放按钮 SVG 改为从外部资源加载，资源更新不再需要重新编译整个程序。
- 模块可以单独构建与替换；只替换业务 DLL 时 CORE 字节保持不变。

## 模块管理

- 设置首页新增“模块管理”，可以选择内部 DLL、校验后暂存、重启安装，并查看各模块版本。
- 安装失败会在启动确认阶段自动恢复原模块并重启；错误身份或无效 DLL 在触碰运行文件前被拒绝。
- 支持一键恢复上一个版本的模块。

## 更新与回滚

- 更新器支持按内容摘要命名的模块包、逐文件摘要比较，只下载变化的二进制与资源包；旧版本仍可使用全量包通道。
- 更新器的安装与回滚继续使用原有事务接口，模块安装复用同一套备份与启动确认流程。

## 下载

- `DotIsle-3.5.2-Setup.exe`：安装版。
- `DotIsle-3.5.2-Portable.zip`：完整解压后运行 `LyricIsland.exe`。
- `DotIsle-3.5.2-SHA256.txt`：文件校验值。
- `DotIsle-3.5.2-Validation.zip`：Actions 构建与界面验收材料。

现有用户可通过应用内更新升级。
