# 点屿 DotIsle 3.5.1

本次更新改善控制中心的滚动、开屏与交互，扩展桌面组件，并为计时与更新提供可选的状态动效。

## 控制中心

- 收紧页头间距，统一标题、说明、正文与待办按钮的参考线。
- 修复壁纸标题区和胶囊底栏附近的明暗断层，保留概览卡片的内容与滚动模糊。
- 改进帧调度、场景准备和显卡选择；开屏完全遮挡内容时不再重复绘制后台卡片。
- 弹层支持连续开合与中途反向，减少动态效果和键盘操作保持直接响应。
- 滑杆和开关采用标准圆弧圆角，开关滑块保持圆形；留白主题移除多余的页头横线。
- 删除 Nothing 主题及专属设置，旧配置回退默认；保留默认、MIUIX、终端、像素与留白的既有设计和背景记录。

## 桌面组件

- 新增便签、纪念日倒数、天气、今日概览、电量、存储空间、世界时钟、快捷启动和专注统计，共十五类组件。
- 每张组件独立保存内容，支持小、中、大三种尺寸；便签、日期、城市、磁盘和启动入口可分别配置。
- 组件表面移除常驻齿轮，统一标题和内容参考线；右键使用文字菜单编辑、调整尺寸或移除。
- 天气使用 Open-Meteo，磁盘和电量读取系统状态；世界时钟使用 Windows 时区规则，专注统计从实际计时积累。

## 液体进度与可选光效

- 番茄钟、倒计时及流程阶段在主胶囊和 Mini 内从左向右填充，卫星岛从下向上填充，到时填满；暂停后液体停住。秒表保持原样。
- 经典岛提供音乐呼吸／输出强弱律动、计时运行光晕和更新彩虹流光，三个开关均默认关闭。
- Mini 不显示外围光效；更新完成或活动停止后，经典岛的光效收敛退出。

## 下载

- `DotIsle-3.5.1-Setup.exe`：安装版。
- `DotIsle-3.5.1-Portable.zip`：完整解压后运行 `LyricIsland.exe`。
- `DotIsle-3.5.1-SHA256.txt`：文件校验值。
- `DotIsle-3.5.1-Validation.zip`：Actions 构建与界面验收材料。

现有用户可通过应用内更新升级。天气数据由 [Open-Meteo](https://open-meteo.com/) 提供。
