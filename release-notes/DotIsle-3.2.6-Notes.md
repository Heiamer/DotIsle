# 点屿 DotIsle 3.2.6

网易云进度改为自动识别 32/64 位客户端结构，扩大 2.x 与 3.x 的兼容范围，取消只启用一个指定 DLL 的限制。正常启动和播放即可连接。

后台拖动按客户端实际底栏范围定位；旧版居中进度条从本机界面资源推导位置。保留暂停稳定、切歌取消、真实跳转确认和主窗口焦点保护。

8 个客户端二进制样本进行静态结构与资源检查；本机当前客户端另做运行验收。详细结果见源码 docs/verification/3.2.6-compatibility.json。未知未来版本仍可能改变结构，未运行的旧客户端不计为完整实测。

项目自有源码根 MIT 署名为 Heiamer；所有仍使用的依赖、字体和图标许可随包保留。

发行包由 GitHub Actions 构建并提供安装版、便携版、源码及 SHA256 清单。
