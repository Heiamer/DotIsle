# 点屿 DotIsle 3.2.7

修复番茄钟和流程计时可能跳过休息、直接进入下一轮专注的问题。

- 休眠、卡顿或后台更新延迟时，只完成当时正在运行的阶段；下一阶段从完整时长开始，不再连续补时跳过休息或专注。
- 流程按钮携带计时状态版本，重复点击或过期的阶段操作会被拒绝，防止连续跳过多个阶段。
- 新建、继续计时、进入下一阶段及锁屏暂停前先结算原状态，空闲、暂停或等待确认的时间不会误计入新阶段。
- 保留番茄钟自动切换、最终轮结束、正向 / 倒向显示，以及流程到时等待确认的原有行为。

新增阶段顺序、延迟更新、重复操作和主进程时间边界回归检查，并通过独立原生进程验证完整流程、暂停恢复和持久化重启。

安装包、便携包、源码和 SHA256 清单均由 GitHub Actions 构建；发布前必须通过工作区测试、页面测试及全部界面验收报告。
