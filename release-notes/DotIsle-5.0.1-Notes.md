# 点屿 DotIsle 5.0.1

5.0.1 是字体可读性补丁，修复灵动岛歌词在磨砂封面上发虚的问题。

## 字体

- 灵动岛默认字体从细体 Noto Sans SC 换为 **HarmonyOS Sans SC**：包含平假名、片假名、日文汉字与简体中文，Regular / Medium / Bold 三档字重让歌词更实。
- 展开卡片歌词字重由 400 提高到 500，大字号沉浸视图提高到 600。
- 字体选择器新增内置 **HarmonyOS Sans SC** 与 **Noto Sans SC** 两项；仍可选择本机已安装字体。
- Noto Sans JP 继续作为日文回退，保留日文假名和汉字的日文字形。

## 其他

- 继承 5.0.0 的全部功能与修复，包括独立信息组件、单窗口控制中心和桌面组件。
- 已在 96 / 144 / 192 DPI 下重新生成音乐卡片截图核对日文歌词、中文翻译与标题的字重和清晰度。
