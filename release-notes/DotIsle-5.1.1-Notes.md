# 点屿 DotIsle 5.1.1

- 修复「浏览器媒体」开启后仍被旧过滤规则拦截的问题，设置即时生效。
- 控制中心直接作为 GUI 启动，不再留下最小化的命令行窗口。
- 新增汽水音乐原生歌词支持和试听片段对齐，找不到匹配时按规范化歌名和主歌手补搜；保留已有歌词源。
- 天气备用源共享城市定位；故障时更快重试，并保留标记为过时的同城读数。
- 便携版改为固实 7z，安装包优化压缩；自动更新保留兼容 ZIP。

## 下载

- `DotIsle-5.1.1-Setup.exe`：安装版。
- `DotIsle-5.1.1-Portable.7z`：便携版，用支持 7z 的工具完整解压后运行 `LyricIsland.exe`。
- `LyricIsland-5.1.1-Portable.zip`：旧版自动更新兼容资产，手动下载请选择上面的 7z。
