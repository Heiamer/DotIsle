# 点屿 DotIsle 5.2.9 正式版

## 通知与全屏

- 飞书、钉钉改用 Windows 系统通知监听，由点屿原生运行，不再使用通知数据库或任务栏闪烁兜底。通知带正文就显示正文，只有系统占位提示时不编造消息内容。客户端须启用 Windows 系统通知；系统授权不足时可在点屿「通知与提醒」查看状态。
- 修复喝水、久坐提醒关闭时仍弹出的问题。两种提醒改为灵动岛及展开卡；喝水可设置每日目标和每次毫升数，点击「已喝」才记录。
- 修复全屏应用隐藏任务栏后岛仍显示的问题，包括任务栏位于顶部的情况。新增「全屏时自动隐藏灵动岛」（默认关闭）；喝水和久坐提醒在全屏游戏或鼠标捕获时跳过，不补弹。

## AI 额度

- 新增原生额度读取，提供 39 个来源配置，不包括 Antigravity，不依赖桥接进程。概览可添加 AI 额度卡；插件默认阈值为 5 小时剩余低于 20% 或本周剩余低于 10%。
- ZCode 有任一时间窗额度就显示额度（包括 0%）；两档均没有才显示剩余 TOKEN。两类数据都未知时显示「—」。
- 中转站低余额提醒默认低于 US$1，可选低于 ¥1 或 1 积分。只比较明确的对应单位，不换汇，不把 TOKEN 当积分。已配置的 New API、Sub2API 和 OpenRouter 可绑定指定 Agent：检测到该 Agent 启动时查一次余额，未绑定则定时查，也可手动刷新。
- 额度岛可跟随 Codex、Claude、ZCode、Cursor 和 DeepSeek Harness。支持多个 Agent 的圆环，以及部分 Codex 桌面结构化问题的选项和文本回复。

## 使用体验

- 液态玻璃提高在浅／深背景上的可见度，玻璃本体支持封面、系统强调色及自选颜色；移除上滑隐藏手势。
- 控制中心集成邮件与验证码联动。天气设置及入门后的城市弹窗可尝试定位，定位不准可手动填写。
- 独立侧边栏暂时移出，原有源码单独归档。

Windows x64。各第三方许可随包附带。飞书、钉钉的真实通知可用性取决于客户端配置及 Windows 通知权限；额度来源依赖对应服务和登录状态。
