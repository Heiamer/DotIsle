# 点屿 DotIsle 3.2.1

- 新增像素 Pixel 主题：融合中文像素字体、16 位机卡带图案、方块图标、阶梯边框和像素进度。
- 默认主题保留原有样式和窗口行为。
- Nothing 按黑白工业风优化，去掉装饰红点，统一点阵计时读数，调整歌词与译文行距，修复同色滑块和空待办实心球。
- 新增云瓷主题：暖灰瓷白、蓝色强调、圆润线条与白色滑钮。
- 新增终端 TTY 主题：等宽字符图标与控件、方正面板、色块唱片与进度；支持深浅色。
- 五个主题选项块支持点击、滑动和重启记忆；新主题不再拖边改变窗口尺寸。
- 五套主题可分别导入本地 PNG / JPEG / BMP，调整透明度、明暗、磨砂度及填满/适应，支持关闭与恢复默认。图片保存在本机，不上传服务器。
- 展开、收起加入轻微 GPU 高斯模糊，轮廓保持清晰，稳定后内容完全锐利；中途反向连续，减少动态效果时关闭模糊。
- 网易云主动探测连接，旧拖动请求在投递前取消；继续以真实时间轴确认。

## 本机验收范围

当前网易云客户端首次连接约 198 ms，10 次真实跳转确认约 186–198 ms，快速连续请求最终确认最新目标，任务栏注意力请求记录为 0，测试后恢复原播放进度与状态。
当前客户端未暴露可用的系统媒体暂停会话，暂停态尚未通过验收；不同客户端版本、最小化和托盘组合仍需分别验证。
展开/收起生产 GPU 截图含反向操作，模糊峰值 1.35 dp；本机合成场景绘制完成 P95 约 4.24 ms（含 GPU 等待，不含系统调度）。
