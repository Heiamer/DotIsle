# 点屿 DotIsle 5.0.9

- 控制中心设置重做为单一双栏面板。左侧查找分类或搜索，右侧直接调整设置。
- 新版手势教程引导你在灵动岛上操作。首次可跳过，完成或跳过后不再自动弹出，也能手动重开。
- 开启自定义布局不再立即改变当前卡片：未调整时沿用当前几何，播放按钮、进度条与滑块样式也沿用当前设置。
- 模块管理从设置侧栏隐藏；十种播放按钮主题展示各自的图标与底色。
- 当前歌词增加柔白光晕，原字仍清晰，翻译不发光。歌词和播放进度条的柔光可分别关闭。
- 进度条滑块样式与原生对齐并加入预览；拖动进度条切换歌词不再导致应用退出。
- 胶囊歌词按实际绘制字重测量宽度，长歌词不再过早省略。
- 精简安装包、便携包和 OTA 的示例资源，保留字体和模块。
- 改善正式版更新检测：GitHub API 受限时优先检查官方发布页，避免被旧备用清单遮挡。
