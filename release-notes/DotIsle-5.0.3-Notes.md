# 点屿 DotIsle 5.0.3

修复设备电量、QQ 邮件验证码与测试版更新，补充天气后备源和灵动岛常驻 Beta。

- **设备电量**：修复蓝牙同一设备的多个接口中，首个无电量节点遮蔽真实读数的问题；支持同一物理容器的 HID 电量关联，已核对本机原道 OriG in 的真实读数与弹窗关联。
- **连接提醒**：连接后立即刷新电量，电量晚到时原位更新弹窗；修复设备身份混淆和正常重连被去重吞掉。
- **断开提醒**：隐藏电量占位横线和过期读数，设备名称使用释放出的空间。
- **性能与体积**：概览滚动复用固定绘图槽位并合并离屏缓存；控制中心共享打包字体、减少大图中间副本，并行初始化后台连接。安装包去除内部验收重复载荷，便携版提高压缩等级。
- **邮件验证码**：支持 4–8 位数字或字母数字组合，保留大小写，提取和复制使用一致规则；修复 QQ 邮件混合验证码漏弹，提示结束后恢复之前的隐藏状态。
- **更新渠道**：GitHub 版本检查与下载优先，国内源降为后备；修复测试渠道短超时，增加 GitHub 发行列表后备读取，并正确比较 RC/Beta/正式版。
- **天气**：主源失败时自动切换至开源 wttr.in，修复失败后持续加载；保留已有缓存并明确数据是否过期。后备源不提供的降水起止时间不做推断。
- **灵动岛常驻（Beta）**：位于灵动岛设置的“交互与系统提示”，默认关闭。开启后空闲整岛完全透明、无文字图标且鼠标穿透；有音乐、计时、更新或提醒等任务时恢复显示。

安装包、便携版与源码包均在下方 Assets。旧版自动更新仍通过校验后的完整更新包完成。
